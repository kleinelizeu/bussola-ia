# Site da Bússola IA

Site estático fictício da Bússola IA, consultoria em agentes de IA para pequenos negócios.
As três páginas são `index.html`, `calculadora.html` e `perguntas.html`.
`index.html` apresenta o serviço.
`calculadora.html` simula uma proposta.
`perguntas.html` reúne dúvidas frequentes.
Para abrir, dê duplo clique em `index.html` ou em qualquer página HTML.
Não há build, servidor local ou dependência externa.
Todos os nomes, contatos, preços, prazos e dados do negócio são fictícios.
